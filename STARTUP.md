## Rules

1. NEVER say a website is live without checking the URL first
2. NEVER say a task is done without verifying it
3. Always check memory files before claiming you don't know something
4. If memory is missing, note the gap and ask for context
5. After completing work, update the relevant memory file

## Verification Checklist Before Reporting

- [ ] Website URL loads correctly (no 404s, no broken CSS)
- [ ] Content is correct (not placeholder text, not old versions)
- [ ] Changes are deployed (not just committed locally)
- [ ] Memory file is updated with what was done
